# Thames Carpentry & Construction Website

A dependency-free, responsive website for Thames Carpentry and Construction. It can be opened directly from `index.html` or served as a static site.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server. No build step is required.

## Customize

- Update the homepage in `index.html` and the focused pages in `services.html`, `portfolio.html`, `about.html`, `certificates.html`, and `contact.html`.
- Adjust shared colors, typography, and layout in `src/style.css`.
- Update the mobile menu and reveal animation in `src/main.js`.
